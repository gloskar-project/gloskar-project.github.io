УСТАНОВКА И ДАННЫЕ

Начните с установки

Скачайте установщик нужной платформы, проверьте источник и сохраните резервную копию, если уже пользуетесь приложением.

Windows

  1. Скачайте EXE со страницы загрузки и сравните SHA-256.
  2. Закройте работающий Gloskar и запустите установщик. Установка выполняется для текущего пользователя.
  3. Открывайте приложение через созданный ярлык. Браузер и сервер для занятий не нужны.
О подписи Windows

Текущий прямой установщик пока без доверенной подписи издателя. Windows может показать «Неизвестный издатель» или SmartScreen. Не отключайте защиту ради установки; при блокировке остановитесь и перепроверьте источник и контрольную сумму.

Основная проверенная среда — Windows 11 x64. Возможность установки не означает проверку всех версий Windows и всех устройств.

Android

Нужны Android 10 или новее и установленный Android System WebView 133+. Само приложение работает без интернета сразу после установки на совместимое устройство.

  1. Сохраните внешний JSON-backup, если приложение уже установлено.
  2. Скачайте подписанный APK со страницы загрузки или по одобренной ссылке магазина.
  3. Откройте APK через системный установщик. Разрешение на установку из выбранного источника меняйте только осознанно; не отключайте системную проверку приложений.

Обновление и резервная копия

Обычное обновление с тем же сертификатом Android сохраняет данные. Не удаляйте приложение и не очищайте его данные для обновления.

  1. Сохраните правки редактора в набор: несохранённый черновик не входит в JSON-backup.
  2. Откройте «Настройки → Сохранить копию» и сохраните полный JSON вне каталога приложения.
  3. Сделайте вторую копию файла. Убедитесь, что сохранены наборы, прогресс и активное занятие.
  4. Для переноса откройте «Восстановить» на другом устройстве. Восстановление заменяет текущую библиотеку — сначала сохраните и её, если в ней уже есть данные.

Переход с LexiLearn на Gloskar

У Gloskar новый Android-идентификатор com.gloskar.app. Он устанавливается рядом с LexiLearn, даже если сертификат прежний. В LexiLearn сохраните правки редактора, затем выберите «Настройки → Сохранить копию». В Gloskar выберите «Восстановить» и откройте этот JSON. Проверьте наборы, статистику и продолжение занятия. Старый LexiLearn и внешнюю копию сохраняйте до завершения проверки; автоматического удаления нет. Это относится и к старым Debug APK.

Windows использует прежнюю библиотеку LexiLearn. Закройте обе версии перед обновлением; не очищайте профиль %APPDATA%\LexiLearn. Новое название папки профиля не требуется.

Проверка без интернета

После установки включите авиарежим и отключите Wi-Fi, полностью закройте приложение и запустите его снова. Создайте или откройте набор, пройдите часть занятия и перезапустите приложение. Прогресс должен сохраниться. Для сайта загрузки, магазинов, обновления WebView и добровольной поддержки интернет нужен отдельно.

Проверка SHA-256

В Windows PowerShell можно проверить скачанный файл командой:

Get-FileHash -Algorithm SHA256 -LiteralPath .\ИМЯ_СКАЧАННОГО_ФАЙЛА

Сравните все 64 символа с суммой на странице загрузки. SHA-256 помогает проверить целостность файла и не заменяет проверку источника или сертификата.
