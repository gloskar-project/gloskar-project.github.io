Приложение

Наборы, карточки, ответы, транскрипции, примеры, статистика, настройки, незавершённое занятие и черновик хранятся локально на устройстве. Разработчик не получает эти сведения и не имеет серверной копии. В приложении нет регистрации, рекламы, аналитики, crash-reporting SDK, обязательных облачных API и встроенных ИИ-запросов.

Android хранит данные в каталоге приложения и не запрашивает разрешение INTERNET. Windows Direct использует локальный профиль Gloskar. Очистка данных или профиля может удалить библиотеку. Храните внешние JSON-копии.

Импорт, экспорт и буфер

Вы сами выбираете файл, вставляете текст и запускаете сохранение или восстановление. Чтение буфера происходит только по нажатию. Полный backup включает наборы, прогресс, настройки и активное занятие, но не несохранённый черновик редактора. Восстановление заменяет текущую библиотеку после проверки и подтверждения.

JSON-копии не шифруются самим приложением. Если выбран облачный файловый провайдер, обработку выполняет он по своим правилам. Gloskar не требует такого провайдера.

Сайт загрузки

На этом сайте нет собственных трекеров, рекламы, сторонних шрифтов, cookie-баннера с аналитикой или обязательных форм. Загрузка файлов и просмотр сайта требуют сети.

При размещении на GitHub Pages и GitHub Releases провайдер может обрабатывать технические HTTP-сведения, включая IP-адрес, User-Agent и путь запроса, по политике GitHub. Библиотека приложения к этим запросам не добавляется.

Внешние сервисы

Нейросеть выбирается и используется вами самостоятельно вне Gloskar. Приложение не хранит API-ключи. ОС, браузер, WebView и магазины работают по собственным правилам; отсутствие аналитики в приложении не означает отсутствия системной диагностики.

Ссылка поддержки ведёт на ЮMoney и открывается только по нажатию. Gloskar не получает платёжные реквизиты и результат перевода, не передаёт в ссылке ваши наборы и не выдаёт привилегий за поддержку. После перехода обработку выполняют браузер и ЮMoney по их правилам. Учебные функции доступны и без сети.
